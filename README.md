# The Controls Exchange — Free BAS Learning

Curated by **Smarty.ctrl**. Follow [Instagram](https://www.instagram.com/smarty.ctrl/) or connect on [LinkedIn](https://www.linkedin.com/in/albert-montilla-593356318/). These are direct profile links; no social embeds or tracking scripts load here.

A free, independent directory of BAS videos, documentation and learning paths, covering Niagara, Honeywell Optimizer/Spyder/CIPer, Johnson Controls Facility Explorer/CCT and Distech EC-gfxProgram.

Home keeps a compact beginners-only link to six BAS foundation blocks from Smart Buildings Academy, followed by optional Niagara 4 orientation from Broudy Precision. Experienced users can browse the Nav tree or use the top name search. The existing practical projects live under Programming paths. The site welcomes free-resource suggestions or broken-link reports by email. Original social sharing artwork accompanies the public link; no social scripts are loaded.

The Controls Exchange uses an original red, charcoal and white learning workbench with flat toolbars, quiet selection and clear reading space. Home belongs under Station above Config. Gray triangle controls only expand/collapse; section labels navigate, and Ctrl/Cmd-click opens independent workspaces. Drag the sidebar edge to widen both panes or the horizontal divider to adjust tree/palette height. Subfolders and advanced filters expand on demand. The Learning palette owns recommended creators, news, release watch, downloads and personal study tools. Creator links, study progress and review history appear at the bottom of Home.

Training covers Niagara AX/N4/N5, Honeywell Optimizer/IRM, Classic Spyder and CIPer Model 30/50, JCI FX/CCT and Distech EC-gfxProgram. Each resource folder shows Videos & playlists first and Documentation / PDFs below. Honeywell has a separate CIPer controllers branch with Model 30 and Model 50 folders. Shared resources retain one ID. Resource lists show controller generation and recording/version context before opening Properties. Separate Watch, Playlist and Read links open the original source directly; Properties retains notes and detailed scope/license information. Search understands common controls terms and spelling variants, runs locally and never sends or stores queries. Optional bookmarks, study marks and notes stay in the browser; export a backup to move them. Original interface branding and artwork do not imply affiliation with the software vendors.

The directory credits and links to original publishers. Third-party videos, manuals and installers are not rehosted. Only free public learning material is listed. Paid training, enrollment catalogs and partner-only references are excluded. Free lessons may demonstrate tools that require a separate practice license. The project has no advertising, affiliate links or paid placements; its purpose is learning, creator credit and community benefit. Original study worksheets are included for personal learning.
