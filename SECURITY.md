# Security policy

Please report a suspected vulnerability through [GitHub’s private vulnerability reporting](https://github.com/albertmontilla472-creator/hvac-smarty-pants-bas-library/security/advisories/new). Do not post exploit details, passwords, recovery codes, tokens, customer information or building-access information in public issues. Ordinary resource corrections can use the public issue page.

Describe the affected page, what you observed and minimal steps to reproduce it. Use your own test data. Please avoid disrupting the service, testing other people’s accounts, automated high-volume probing, or testing the independent publishers linked by this directory. Acknowledgment or repair times are not guaranteed.

The maintained release is the version currently published at [The Controls Exchange](https://albertmontilla472-creator.github.io/hvac-smarty-pants-bas-library/). Previous exported copies may lack later fixes.

This static directory has no visitor accounts, payment processing, backend, visitor-upload service or third-party runtime scripts. Optional study notes remain in the browser. Keep notes non-sensitive: browser storage is not encrypted by this app, and GitHub project sites under the same account share an origin.

External sites and downloads are controlled by their publishers. Direct links and reviewed domains reduce avoidable risks; they do not guarantee the future safety of a third-party site. The directory does not mirror or automatically run installers.

Security controls reduce risk; they do not guarantee protection if a maintainer account, publishing credential, device, browser or hosting service is compromised. Hosting uses GitHub Pages; it does not provide custom response headers for this project, so the HTML content security policy has the limitations of a metadata policy.
