Privacy notice

Updated October 14, 2026

Who operates this directory

HVAC Smarty Pants maintains this independent BAS learning directory. Contact the maintainer through the public GitHub issue page for questions, corrections or concerns. Avoid posting private details, credentials, customer information or building-security information in a public issue.

Browse without an account

The directory does not require a sign-in, mailing-list subscription or payment. We have not added advertising, visitor analytics, tracking pixels, third-party fonts or embedded video players. Following a resource link opens the original publisher’s website, where that provider’s privacy and access rules apply.

Optional study records on your device

If you choose to save a lesson, mark it studied, write a note or restore a backup, the directory uses your browser’s local storage to remember that information. These records are not uploaded to the maintainer. Previously saved records are read to provide the features you chose. No new study-storage record is written just to browse the page. Local records remain until you clear them or your browser removes them. Keep notes non-sensitive. This app does not encrypt browser records, and other project sites under the same GitHub account share the website origin.

Control and remove your records

Export a backup if you want to keep your records, then use “Clear local study data” on the Sources & updates page to remove this directory’s records from the current browser. Clearing site data in your browser also removes them. Exported backups remain wherever you saved them; delete those files yourself if you no longer want them. A different browser or website address has separate storage.

Hosting and external services

GitHub Pages hosts the public website. GitHub logs and stores visitors’ IP addresses for security, including visits without a GitHub sign-in. We do not control those logs or retention. GitHub’s privacy statement governs its processing. GitHub issues are a separate public service: information you post there may be visible to anyone and is governed by GitHub’s policies.

Questions and policy changes

Use the public issue page for privacy questions without including sensitive information. We can discuss an appropriate way to handle information that should not be public. This notice will be updated if the directory adds data collection, accounts, analytics or other services.
